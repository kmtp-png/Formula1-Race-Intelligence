What is F1 Race Intelligence?＋

A Formula 1 data analytics project using visual storytelling to explore race and team performance through charts and dashboards.

Is the circuit map showing a real live race?＋

No. The circuit and telemetry values are a front-end simulation. Real live tracking would require a permitted live timing/data API and integration.

Where is the actual Tableau dashboard?＋

Use the Open Tableau Public button above. Replace its URL in index.html with your published workbook URL to link directly to your work.

What can I learn from the charts?＋

Depending on your sheets, compare team points, follow trends across races and explore the Tableau story interactively.

Can I update this site later?＋

Yes. Edit the HTML, CSS or JavaScript files, upload replacements to the same GitHub repository and commit the changes.
