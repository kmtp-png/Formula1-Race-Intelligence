## Dataset profile
Workbook profile (from the supplied Excel file): circuits: 29 records × 9 columns; championship_standings: 311 × 10; lap_intelligence: 3,814 × 14; qualifying_results: 3,130 × 16; race_results: 6,464 × 42. Total data rows across sheets: 13,748 (header rows excluded). Full-row duplicate counts: 0 in each sheet. Missing values: no nulls were found in circuits, championship_standings, lap_intelligence or qualifying_results; race_results has 6,130 null total_race_time_s, 6,068 null dnf_reason, and 396 nulls each in finish_position, positions_gained, and gap_to_leader_s. These nulls may be structurally valid (e.g., DNF or non-classified records) and should not be blindly replaced with zero. Dataset values appear curated/synthetic in places (for example, 2010 championship standings naming modern drivers); do not describe it as an official historical dataset unless provenance is verified.
