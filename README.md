# F1 Race Intelligence — Animated V2

Responsive static website with animated gradients, ambient floating particles, cursor glow, scroll progress rail, moving SVG circuit marker, simulated telemetry, overtake interaction, animated insights cards, FAQ and author credit.

## Important
- The circuit marker and telemetry are **simulated front-end visuals**, not live race GPS or timing data.
- Replace the `href` on the **OPEN TABLEAU PUBLIC** button in `index.html` with the exact URL of your published Tableau workbook.
- Author credit currently reads **TEJSWA PUROHIT** Edit it in `index.html` if needed.

## Publish
Upload `index.html`, `style.css`, `script.js`, and `README.md` to the root of your existing GitHub repository and commit changes. Keep the three site files together. GitHub Pages republishes static changes from the configured branch/folder.
